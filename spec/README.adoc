= wokelang — Specification Directory
:toc:

== Overview

This directory contains the canonical language/query specification files for wokelang.

== Contents

=== grammar.ebnf
A generated, synchronized copy of the canonical EBNF grammar, whose single
source of truth is `grammar/wokelang.ebnf` (verified against the live
`src/lexer` and `src/parser`). Do not edit the grammar here; edit
`grammar/wokelang.ebnf` and run `scripts/check-grammar-sync.sh --sync`. CI runs
`scripts/check-grammar-sync.sh` to fail the build if the two ever drift apart.

=== SPEC.core.scm
Core specification in Scheme format.

== Conventions

- All specification files use the `@taxonomy: spec/*` annotation prefix
- Grammar changes must update both the original and this canonical copy
- SPEC.core.scm follows the RSR META-FORMAT-SPEC
