## Architecture Decisions

### Type System: Hindley-Milner
- ✅ Principal type inference
- ✅ Polymorphism
- ✅ Unification
- Future: Generic functions with explicit type params

### Interpreter: Tree-Walking
- ✅ Fast development
- ✅ Easy debugging
- ⚠️ Slower execution (~10-100x vs. bytecode)
- Future: Bytecode VM exists but not integrated

### Concurrency: Thread-Based (Simplified)
- ✅ Simple spawning
- ✅ Isolation
- ❌ Message passing (blocked)
- Future: Arc-based design or serialized messages

### Security: Capability-Based
- ✅ Object-capability model
- ✅ Interactive consent
- ✅ Audit logging
- Future: Temporal capabilities, capability transfer
