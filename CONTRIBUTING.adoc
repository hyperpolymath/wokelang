== Contributing to WokeLang

Thank you for your interest in contributing.

=== Getting Started

[arabic]
. Fork the repository
. Create a feature branch (`+feat/my-feature+`)
. Ensure SPDX headers on all new files (`+MPL-2.0+`)
. Run `+panic-attack assail+` before committing
. Submit a pull request

=== Code Quality

* All code must have detailed annotations
* No dangerous patterns: `+believe_me+`, `+assert_total+`, `+sorry+`,
`+Admitted+`, `+unsafeCoerce+`, `+Obj.magic+`
* Tests required for new functionality

=== Reporting Issues

Use GitHub Issues with clear reproduction steps.
