== One-paragraph summary

WokeLang makes *consent* and *affine-use safety* first-class: the type system is
intended to discharge the hard reasoning about destructive or sensitive
operations so the user does not have to. The production implementation is a Rust
toolchain (lexer, parser, typechecker, bytecode VM, tree-walking interpreter,
LSP, DAP, formatter, linter, REPL, stdlib); an OCaml reference core provides an
independent semantics cross-check. The frontier workstream integrates *echo
types* — a constructive Agda formalization of fiber-based structured loss — into
the typechecker, backed by a machine-checked proof narrative.
